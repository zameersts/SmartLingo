Welcome to SmartLingo Pro! 👋

SmartLingo Pro is your personal, AI-powered translator built right into the NVDA screen reader. We built this addon so you wouldn't have to constantly switch windows or juggle different translation websites. Translate copied text or speak into your microphone—all without leaving what you're currently doing!

🌟 What can it do?

  • Instant Translations: Just copy some text, press a hotkey, and get an instant AI translation read out to you.
  • Speak to Translate: Press a hotkey, speak into your microphone, and we'll translate your voice!
  • Smart Language Detection: You don't even need to tell it what language you're copying—it'll figure it out automatically.
  • Quick Language Swap: Easily switch between your source and target languages. It even does this automatically if it detects you're already reading in your target language!
  • AI Assistant: Press NVDA+Alt+Enter to open the chat window. It remembers the whole conversation, answers your questions instead of translating them, and replies in the language you write in. Pick Groq or Gemini for it in the settings, under "AI Assistant model". This is separate from the translation model, so you can translate with the free Google Translate and still chat with Groq. The window stays out of your way and does not steal focus when a reply arrives.
  • Auto-Copy: As soon as a translation is ready, we copy it to your clipboard so you can paste it anywhere.
  • Auto-Translate Clipboard (optional): Turn this on and any text you copy is translated straight away, without pressing the translate key. It is off by default, and SmartLingo never re-translates its own output.
  • Spoken Language Setting: Tell SmartLingo the language you actually speak. This is separate from the translation languages, and it is what keeps English words in English when you mix them with Urdu, Hindi or Bengali.
  • Automatic Updates: Don't worry about missing new features! SmartLingo checks for new versions on GitHub at startup and again every 6 hours, and only speaks up when there is actually something new.
  • Pick your AI: Choose between Google Gemini, Groq, or Google Translate based on what you prefer (Google Translate does not require an API key for text translation).

🛠️ What do you need to use it?

It's pretty simple to get started, but you will need a couple of things:

  • NVDA Screen Reader (version 2024.1 or newer).
  • Windows 10 or a newer version.
  • An API Key: This is basically a password that lets the addon talk to the AI. You can get one for free from Groq or Google AI Studio (Gemini). (Note: If you use the built-in Google Translate model, you do not need any API key for text translation. However, voice features will still require a Groq API key.)
  • (Optional) A microphone for voice input. Note: Voice input requires a Groq API key. Gemini and Google Translate do not support speech recognition (STT) natively in this addon.

🚀 How to Install

  1. Download the SmartLingo.nvda-addon file from our Releases page.
  2. Just double-click the file! NVDA will handle the rest.
  3. When NVDA asks, let it restart.
  4. Once NVDA is back up, go to NVDA Menu > Preferences > Settings, find SmartLingo Pro in the list, and paste in your API key.

⚙️ Customizing SmartLingo

You can tweak how SmartLingo works by going to NVDA Settings > SmartLingo Pro. Here's what you can change:

  • AI Model & API Key: Choose which AI brain you want to use and give it the key.
  • AI Assistant model: Choose which AI runs the chat window: Groq or Gemini. This setting is completely separate from the translation model, so switching one never affects the other. Groq is selected by default. Google Translate and DeepL translate text, they cannot hold a conversation, so they are not offered here.
  • Languages: Set what language you usually translate from (or leave it on Auto-detect) and what language you want things translated into.
  • Auto-Swap & Language for swapping: If you try to translate something that's already in your target language, SmartLingo will be smart enough to flip the languages around for you!
  • Auto-copy: Decide if you want every translation to be automatically copied to your clipboard.
  • Automatically translate newly copied clipboard text: Optional, and off by default. When it is on, any text you copy with Ctrl+C is translated automatically, so you do not have to press the translate key each time. Text that SmartLingo itself puts on the clipboard is skipped, so it can never translate its own output in a loop.
  • Dictation script: The script your dictated text is converted to, for example Roman Urdu. Used by voice typing only.
  • Spoken language for voice input: The language you actually speak, used by both voice translation and voice typing. Leave it on automatic detection unless you speak only one language. Forcing the wrong language here is what makes Whisper write your English words in the wrong script.
  • Automatically check for updates on startup: On by default. The check also repeats every 6 hours, so you do not have to restart NVDA to notice a new release. Untick it to stop checking altogether. Check for Updates now checks immediately and tells you the result either way.

🎤 Using Your Voice

Want to just talk? It's easy!

  • Press NVDA + Alt + V, say what you want to translate, and press the shortcut again to stop. It says "Recording started for translation...".
  • For voice typing (dictation) without translation, press NVDA + Alt + D to type directly into an active edit box. It says "Recording started for typing...".
  • To cancel at any time, press NVDA + Alt + C. This works while you are recording and while your speech is being transcribed, in which case it says "Transcription cancelled."
  • While voice input is running, the other SmartLingo shortcuts will say "Voice input is in progress, please wait." rather than starting on top of it.
  • Quality tips: SmartLingo trims the silence at the start and end and boosts quiet recordings before sending them, so you do not have to leave long gaps. A recording with no speech in it is refused with "No speech was detected." instead of being sent off to be turned into invented text. Recordings shorter than 0.4 seconds are refused, recording stops automatically at 5 minutes, and a long recording is given 90 seconds to be transcribed before it is timed out.
  • Important: Voice input (both voice translation and dictation) requires a Groq API key to function. This is because speech-to-text is handled by Groq's Whisper API. Gemini and Google Translate do not support speech-to-text natively in the addon. You must provide a Groq API key in the settings to use voice features, even if your translation model is set to Gemini or Google Translate.
  • PyAudio is included with the addon and does not need to be installed separately.

🔔 What you will hear

SmartLingo always tells you what it is doing, so you never have to guess whether your key press registered:

  • "Recording started for translation..." or "Recording started for typing..." when the microphone opens.
  • "Transcribing..." once, after you stop, once the tail of your audio has been captured.
  • "Recording was too short.", "No speech was detected. Please check your microphone.", or "Recording limit of 5 minutes reached. Stopping." when something is wrong with the recording itself.
  • "Cancelling transcription..." if you press the same key again while it is transcribing.
  • A specific message for each real problem, such as an invalid Groq API key, a wrong speech language, a rate limit, no internet connection, or the speech service being temporarily unavailable. It will also tell you plainly when the service returned an empty result.
  • Dictation never types an error message into your document. If the focus moved somewhere that cannot accept text, it leaves the text on your clipboard and tells you instead.
